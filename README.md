# llm-trading-backtest

**질문 하나를 끝까지 검증한 기록** — *"LLM이 스스로 판단해서 거래하면 돈을 버는가?"*

**답: 아니오.** LLM에게 매매를 맡기는 구성 **7가지**(입력 3종 · 팩터 생성 · 리스크 게이트 · 최신 모델 교체 · 멀티에이전트)를 전부 시험했고 전부 기각됐다. 살아남은 건 LLM이 없는 규칙 전략 두 개다.

실전 배포(젯슨 라이브)는 → **[edge-llm-trading-bot](https://github.com/iam-raccoon/edge-llm-trading-bot)**. 여기서 결론 → 저기서 실행.

> 📊 크립토 **매매봇** 실험(v1~v4) → [RESULTS.md](RESULTS.md)
> 📈 국내주식·PEAD·**팩터** 실험 + **크립토 팩터**(v6 · 저변동성 롱숏) → [RESULTS_KR.md](RESULTS_KR.md)
>
> *아래 "살아남은 것"의 크립토 저변동성 롱숏은 RESULTS.md가 아니라 **RESULTS_KR.md**의 v6-크립토 절에 있다.*

## 결론

### LLM 역할별 최종 성적

| LLM에게 시킨 일 | 어떻게 검증했나 | 결과 |
|---|---|---|
| **수치 보고 매매 판단** | Alpha Arena (실제 돈 $10k × 프런티어 6모델) | ❌ 6개 중 4개 손실, **GPT-5 −62.66%** |
| **텍스트 보고 매매 판단** | v5 PEAD, OOS 697건 | ❌ IS +3.66% → **OOS −2.60%** |
| **텍스트+수치 보고 판단** | v5 A/B, 변수 하나만 바꾼 대조실험 | ❌ IS +6.64% → **OOS −1.21%** |
| **알파 팩터 수식 생성** | v6, 8라운드 69팩터 | ❌ **단타 0/69**, 생존분은 교과서 팩터 재발견 |
| **리스크 이벤트 게이트** | 천장 측정(완벽 작동 가정) | ❌ **+0.013%p** (거래비용 0.24%p) |
| **최신 모델로 교체** | qwen3.6:35b·gemma4:12b, 697건 재판정 | ❌ 판정은 19~26% 달라져도 **알파 불변** |
| **멀티에이전트(앙상블)** | 3모델 만장일치, 추가 호출 0회 | ❌ **A 단독과 소수점까지 동일** |

**세 가지 입력 구성이 전부 같은 방식으로 실패했다** — 인샘플에서 좋고 아웃오브샘플에서 무너진다. 입력을 바꿔도 결과가 같다는 건 문제가 입력이 아니라 **과제 자체**(LLM에게 가격 예측을 시키는 것)에 있다는 뜻이다.

**그리고 LLM의 판단은 실제로 정확했다.** 공시를 읽고 매출 −66.7%·적자전환을 정확히 악재로, 무상증자를 "실질 호재 아님"으로 정확히 분류했다. 수치를 주니 판단도 31% 바뀌었다. **틀려서 실패한 게 아니라, 정확한 판단이 미래 가격과 무관해서 실패했다.**

## 이 저장소의 진짜 자산 — 착시를 일곱 번 죽인 검증 절차

좋아 보이는 숫자가 나올 때마다 무너뜨린 기록. **이게 전략보다 값어치 있다.**

| # | 좋아 보였던 숫자 | 정체 | 잡아낸 방법 |
|---|---|---|---|
| 1 | 급등추격 **+45.14%** | 슬리피지 무시 | 편도 0.3~0.5% 반영 → −4.45% |
| 2 | 공시 키워드필터 **+73.78%** | 초대박 3개가 손익의 82% + 생존편향 | LLM 質판정 대조군 → +4.25% |
| 3 | 장투 2024 **+9.8%** | 룩어헤드(오늘 유니버스를 과거에 적용) | 시점별 자격 재판정 → −1.6% |
| 4 | v5 PEAD **+3.66%** | 구간 과최적화 | OOS 697건 재현 → −2.60% |
| 5 | 자사주 이벤트 **t=4.32** | 140칸 스캔의 선택 효과 | 봉인 홀드아웃 → t=0.22 |
| 6 | 저변동성 롱온리 붕괴 | 시장 베타 | 롱숏 분리 → 알파는 실재, 롱온리가 문제였음 |
| 7 | v5 A/B **+6.64%** | 다시 구간 과최적화 | OOS 697건 → −1.21% |

### 반복해서 쓴 방어 장치

- **사전 등록** — 통과 기준을 *결과 보기 전에* 코드에 하드코딩. 사후 변경 금지
- **홀드아웃 봉인** — `--unseal` 없이는 접근 불가. 코드가 막지 않으면 사람은 반드시 훔쳐본다
- **생존편향** — 상장폐지 종목을 유니버스에 되살림 (KOSPI 49 · KOSDAQ 101 · 크립토 40)
- **룩어헤드** — 시점별 시총·유동성 재판정. 신호는 종가, 진입은 다음날 시가
- **거래비용** — 수수료+거래세+슬리피지 왕복 차감 (한국 0.41~0.81%p / 크립토 0.12%p)
- **다중검정** — 평가한 가설 수를 기록하고 본페로니 임계 t를 함께 보고
- **중첩 구간** — H+h를 매일 계산하면 t가 √h배 부풀어난다. 비중첩으로 재계산
- **실행 가능성** — 공매도 가능 여부·상장 여부·거래대금 문턱. *알파가 있어도 못 치면 없는 것*
- **대조군** — 무작위 날짜 매수, 규칙 전체매수. *기준선 없이는 −4%가 나쁜 건지 알 수 없다*

### 엔진 검증 (분석 전에 반드시)

부호가 알려진 시드로 먼저 재본다. 실제로 이렇게 버그를 잡았다:

- 저변동성 팩터가 롱온리 **+inf, 승률 89%** → 알파가 아니라 **거래정지 종목**을 전부 고른 것
- 실적공시 대조군이 음(−)으로 나와야 스캐너가 맞다 → 검산 통과 확인
- `scipy 1.8.0` × `numpy 2.2.6` 바이너리 불일치로 스피어만 상관이 통째로 깨져 있었음

## 실행

```bash
pip install -r requirements.txt

# 크립토 규칙봇 vs LLM
python backtest.py --days 7 --cpu --model qwen3:30b

# 국내주식 트랙
python surge_backtest.py --slip 0.003      # 급등추격
python trend_backtest.py                   # 장투
python trend_pit_universe.py               # 룩어헤드 검증
python delisted_recheck.py --track trend   # 생존편향 검증

# v5 PEAD
python v5_oos.py events && python v5_oos.py judge && python v5_oos.py alpha

# v6 팩터
python v6_factor_lab.py --market kospi     # 엔진 검증(시드 팩터)
python v6_llm_mine.py --rounds 8           # LLM 팩터 마이닝
python v6_crypto.py --full                 # 크립토(상폐 포함)
```

LLM 판정은 ollama 구조화 출력(JSON 스키마)을 쓴다. qwen3는 **thinking 모델이라 `think:false`가 필수** — 없으면 사고 토큰이 `num_predict`를 다 먹고 본문이 빈 채 반환된다(`done_reason=length`).

**판정 속도**: `LLM_NUM_GPU=99`로 GPU 오프로드하면 같은 697건이 **CPU 13시간 → GPU 42분**이다(기본값 0=CPU는 기존 판정 재현성 유지용). **MoE는 CPU에서 안 빠르다** — qwen3.6:35b(MoE) 22초/건 vs gemma4:31b(Dense) 216초/건. CPU는 메모리 대역폭 병목이라 dense는 토큰마다 전체 가중치를 읽는다. *여기 나오는 `gemma4:31b`는 이 속도 비교용이고, 판정에 실제로 쓴 gemma는 `gemma4:12b`(모델 E)다 — 31b는 CPU로 30시간이 걸린다는 추정이 나와 판정에서 뺐다.*

## 배포 상태

젯슨에서 **매매 판단을 하는 것은 전부 순수 규칙**이다. LLM이 매매 결정에 닿는 경로는 없다.

| 시각 | 작업 | LLM |
|---|---|---|
| 상시 | 크립토 HTF 추세추종 (페이퍼) | 없음 |
| 평일 16:10 | 장투 포워드 페이퍼 | 없음 |
| 평일 16:20 | 전략 B 포워드 페이퍼 | 없음 |
| 평일 08:00 | 아침 시황 브리핑 | **있음** (읽기·요약) |

LLM이 남아있는 자리는 **결정이 아니라 인식**이다 — 뉴스 요약, 비정형→정형 변환, 그리고 리서치 가속(이 저장소의 공시 판정 1,142건이 로컬 qwen3:30b로 돌아갔다).

## 왜 "아직"이 아니라 "구조"인가

1. **GPT-5도 실제 돈으로 −62.66%였다** — 로컬 30b의 한계가 아니다
2. **입력을 세 번 바꿨는데 세 번 다 같은 방식으로 실패했다** — 모델 성능이 아니라 과제 구조의 서명
3. **모델을 직접 갈아끼워 확인했다** — 세대(qwen3→3.6)·계열(qwen→gemma)·구조(MoE→Dense)를 다 바꿔도, **가장 다르게 판단한 모델(일치율 74.2%)의 알파가 오히려 나빴다**
4. **3모델 앙상블이 1모델과 소수점까지 같았다** — 앙상블은 *오차* 독립을 전제하는데, 우리 문제는 오차가 아니라 **무관함**이다
5. **LLM의 판단 자체는 정확했다** — 정확한 판단이 미래 가격과 무관할 뿐
6. **규칙으로도 여섯 번 실패했다** — LLM 문제가 아니라 시장 문제

> **공개된 텍스트를 읽고 미래 가격을 맞히는 일 자체가 성립하지 않는다.**
> 그 정보는 이미 가격에 들어 있다. 모델이 더 좋아져도 정보가 없는 곳에서 정보를 만들 수는 없다.
